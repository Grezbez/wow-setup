# Addons

[Back](./)

## Quests and leveling
- **Questie**: quest helper map
- **QuestieDB**: Questie quest data
- **QuestieTrace**: quest path lines
- **Forever Quest Tint**: quest color tint
- **What's Training?**: trainable spells list
- **SkillUp Forever**: skill-up tracker

## Interface
- **BetterBlizzFrames**: improved unit frames
- **BetterBlizzPlates**: improved nameplates
- **MoveAny**: move UI elements
- **ManaRise**: animated resource bars
- **Leatrix Maps**: better world map
- **Good Addons**: addon and minimap manager
- **ForeverCore**: shared addon library

## Combat
- **Details! Damage Meter**: damage and healing meter
- **SpellActivationOverlay**: proc glow alerts
- **Does It Die**: mob kill check
- **HealBot Continued**: click-to-heal frames
- **Formwise**: druid form bars

## Bags, gear and gold
- **Baganator**: all-in-one bags
- **Syndicator**: items across characters
- **Auctionator**: auction house helper
- **Pawn**: gear upgrade scores

## Exploring and collecting
- **RareScanner**: rare mob alerts
- **DungeonJournal**: dungeon boss info
- **Library Books**: book collection tracker
- **Forever Loot Sparkles**: loot highlight sparkles
